# Day 6 – What is Machine Learning? Build an Intuition 🤖

## Overview

For Day 6, I explored the fundamentals of **Machine Learning** using Google's **Teachable Machine**.

I created an image classifier and experimented with how **data quantity and data quality affect model performance**.

## 🎯 Project

I created a visual classifier with two classes:

- 🧴 Bottle
- 📱 Mobile Phone

## 🔗 Trained Model

[View My Teachable Machine Model](https://teachablemachine.withgoogle.com/models/TPAIOw-z8/)

## 🧪 Experiments

### 1. Initial Training

I trained the model using a smaller amount of training data for both classes and tested its predictions using a bottle and a mobile phone.

### 2. More Training Data

I added more images to both classes and trained the model again.

The additional data included different positions, angles, distances, lighting conditions, and backgrounds.

I then tested the model again and compared its predictions with the initial training.

### 3. Noisy / Inconsistent Data

I experimented with lower-quality and inconsistent training examples, including variations in image quality, lighting, positioning, and partially visible objects.

This helped me understand how poor-quality or inconsistent data can affect model predictions.

## 💡 3 Key Observations

### 1. More Training Data Helps

More training examples can help a model learn different appearances of an object and make more reliable predictions.

### 2. Data Variety Matters

Different angles, lighting conditions, distances, and backgrounds help a model become more robust.

### 3. Data Quality Matters

Incorrectly labeled, noisy, or poor-quality data can negatively affect model performance.

A model learns patterns from its training data, so poor input data can lead to poor predictions.

## 🧠 Key Takeaway

This experiment helped me understand that **machine learning is highly dependent on training data**.

The quantity, variety, accuracy, and quality of data all influence what a model learns and how well it performs on new examples.

> **Better Data → Better Learning → More Reliable Predictions**
